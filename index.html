プロジェクト

ウェブ

Shopping Gaming

C# を使用して、フロントエンドからバックエンドまで実装したフル機能の ECサイトを開発しました。 このプラットフォームには、商品閲覧、カート管理、注文処理、自動メール通知、そして VNPay との決済連携が含まれています。

ビュー ビュー

ウェブ

JWT

Node.js を用いてバックエンドを構築し、フロントエンドには React を使用しました。 JWT 認証を導入し、ユーザーの登録・ログイン機能、権限管理（ロールベースアクセス）を実装しました。 RESTful API の設計原則に基づき、保守性と拡張性の高い API を構築しています。 また、従来の MySQL ではなく XAMPP を活用し、ローカル環境でのデータベース管理・接続設定にも習熟しています。

React

香水のウェブサイト

チームで協力しながら、React、Tailwind CSS、React Router、Redux Toolkit、Ant Design を用いて、 機能満載の香水ショッピングサイトを構築します。 このサイトでは、管理者がコンテンツを簡単に管理・運用できるだけでなく、 購入者も快適に買い物を楽しむことができます。 私たちは、双方にとってスムーズで便利なユーザー体験を提供することを目指しています。
